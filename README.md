## The line

> My smart fridge left me: I only open it when I'm lonely at 2 a.m.

## Run

```sh
ENTRY_OUTPUT_DIR=/output python3 main.py
```

Writes one funny line (under 200 characters) to `$ENTRY_OUTPUT_DIR/entry.txt`.
Deterministic: repeated runs produce byte-identical output. Stdlib only, no network.
